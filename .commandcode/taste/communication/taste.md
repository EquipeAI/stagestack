# Communication Style

- Communicates with terse, rapid-fire affirmations (yes / yup / agreed / sounds good) and prefers a lightweight, fast back-and-forth. Confidence: 0.9
- When unsure, asks for clarification or a concrete example before agreeing ("What do you mean?", "give me an example please", "What do you mean by scaffolding?") — expects the assistant to be equally explicit rather than assume understanding. Confidence: 0.8
- Prefers exact, concrete figures over estimates — asks whether the tools can return exact costs (e.g., domain pricing) and values precise numbers in answers; repeatedly follows up to get exact prices ("How much for stagestack.ai or .dev?"). Confidence: 0.75
